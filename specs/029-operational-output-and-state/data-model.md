# Data Model: Operational Output and State Rebinding

## Verbose diff inspection

A property difference is a managed dimension differing in any source-to-baseline, destination-to-baseline, or source-to-destination comparison. Each rendered group has one source, baseline, and destination value; absent state is explicit.

## Human mutation summary

A payload-file action changes a managed file and contributes to human file counts. Directory setup is supporting work and does not contribute. An aggregate blocker has a reason and available safe managed path evidence.

## Project binding assessment

The raw descriptor digest identifies the published descriptor. Project root, destination home, and resolved mapping digest are mapping-relevant binding fields. A raw digest-only change is rebind-eligible; a changed mapping-relevant field retains full safety inspection.
